การตรวจจับและตัดภาพไข่แดงอัตโนมัติด้วย HSV Masking

สไลด์ 03 / 13

โจทย์หลัก: ค้นหาตำแหน่งไข่แดงในภาพถ่ายสดโดยที่ผู้ใช้ไม่ต้องลากมือเอง และต้องมีความทนทานต่อแสงและสีพื้นหลัง

🌈 ปริภูมิสี HSV (Hue, Saturation, Value)

การแยก "เฉดสีแท้จริง (H)" ออกจาก "ความสว่าง (V)" ทำให้ระบบไม่ได้รับผลกระทบจากแสงมืดหรือจ้า:

  • Hue (5° – 55°): ครอบคลุมเฉดสีไข่แดงตั้งแต่สีส้มเข้ม (เบอร์ 15) จนถึงเหลืองอ่อน (เบอร์ 4)
  • Saturation (≥ 0.25) [จุดชี้ขาด]: บังคับความสดของสี ทำให้ ตัดพื้นหลัง จานสีขาว และไข่ขาวทิ้ง 100% เพราะสีเหล่านั้นมี Saturation ต่ำมาก (< 0.25)
  • Value (≥ 0.20): ตัดเงาดำและมุมมืดของภาพทิ้ง
💡 ข้อดีทางวิศวกรรม: ใช้วิธีทางคณิตศาสตร์ความเร็วสูง ใช้เวลาประมวลผลเพียง ~15 ms เร็วกว่า Deep Learning กว่า 10 เท่า

💻 โค้ดคำนวณการกรองสีจริง (Python)

import numpy as np
from skimage.color import rgb2hsv

# 1. แปลงภาพเป็น HSV
hsv = rgb2hsv(arr / 255.0)
h = hsv[:, :, 0] * 360.0
s = hsv[:, :, 1]
v = hsv[:, :, 2]

# 2. หน้ากากกรองเฉพาะเนื้อไข่แดง
mask = (
    (h >= 5.0) & (h <= 55.0) &
    (s >= 0.25) &
    (v >= 0.20)
)

การคัดแยกสิ่งรบกวนด้วย Connected Component Analysis

สไลด์ 04 / 13

กรณีศึกษาเคสยาก: หากมีวัตถุสีส้มอื่นอยู่ในภาพ (เช่น ชิ้นแครอท หรือมะเขือเทศ) การใช้พิกเซลรวมจะทำให้กรอบลากคลุมผิดพลาด จึงต้องใช้ Connected Component Analysis (CCA) แยกกลุ่มวัตถุอิสระ

🔬 หลักการทำงานของ Largest Blob Selection

  1. นำไบนารีมาสก์มาติดฉลาก (Label) พิกเซลที่เชื่อมต่อกันเป็นก้อนๆ
  2. คำนวณคุณสมบัติทางกายภาพของแต่ละก้อนด้วย regionprops()
  3. เลือกเฉพาะ "ก้อนที่มีพื้นที่ (Area) ใหญ่ที่สุดเพียงก้อนเดียว"
from skimage.measure import label, regionprops

lbl = label(mask)
props = regionprops(lbl)

# เลือกล็อกเป้าเฉพาะก้อนที่มีขนาดใหญ่ที่สุด
largest = max(props, key=lambda p: p.area)
cy, cx = int(largest.centroid[0]), int(largest.centroid[1])

เรขาคณิตการคำนวณพิกัดตัดภาพจัตุรัส (Square Crop Math)

สไลด์ 05 / 13

สเต็ป 1: หาขนาดกล่องจัตุรัส

Size = max(W, H) × 1.05

เลือกด้านที่กว้างหรือสูงที่สุดเพื่อไม่ให้ไข่แหว่ง และคูณ 1.05 เพื่อเผื่อขอบ (Padding 5%) สบายตา

สเต็ป 2: หามุมบนซ้าย (x₁, y₁)

x₁ = cx - Size/2
y₁ = cy - Size/2

ถอยจากจุดกึ่งกลางมวล (cx, cy) ไปทางซ้ายและขึ้นข้างบนครึ่งกล่อง เพื่อเริ่มตีกรอบครอบคลุมไข่แดง

สเต็ป 3: มุมขวาล่าง & Clamp

x₂ = x₁ + Size | y₂ = y₁ + Size

บวกขนาดกล่องไปข้างหน้า พร้อมคำสั่ง max(0, x1) ป้องกันพิกัดทะลุออกนอกขอบภาพ 100%

🔢 ตัวอย่างตัวเลขจริง: ไข่แดงกว้าง 200 px, สูง 180 px, กึ่งกลาง (500, 400) ➔ Size = 200 × 1.05 = 210 px (ครึ่งกล่อง = 105 px) ➔ ตัดพิกัด image.crop((395, 295, 605, 505)) ได้ภาพจัตุรัสเป๊ะ!

Center Circular Mask 42% เจาะใจกลางไข่แดงตัดแสงสะท้อน

สไลด์ 06 / 13

ปัญหาสำคัญทาง Computer Vision: "ภาพถ่ายเป็นสี่เหลี่ยม แต่ไข่แดงเป็นวงกลม" หากนำภาพสี่เหลี่ยมที่ตัดได้มาเฉลี่ยค่าสีทันที จะได้ผลลัพธ์ที่ผิดเพี้ยนอย่างมีนัยสำคัญ

🚫 2 ปัญหาใหญ่ที่ต้องกำจัด

  • มุมทั้ง 4 ของภาพสี่เหลี่ยม: ยังมีเศษไข่ขาว (Egg Albumen) หรือขอบจานสีขาวปนอยู่ หากนำมาเฉลี่ยจะทำให้ค่าสีจางลง
  • แสงสะท้อนขอบไข่ (Specular Highlights): ไข่แดงมีความโค้งนูนและสะท้อนหลอดไฟนีออนด้านบน ทำให้เกิดจุดขาวจ้าหลอกตา
💡 วิธีแก้ปัญหา: ใช้ Circular Mask รัศมี 42% (เว้นขอบ 8%) เจาะดูดเฉพาะเนื้อไข่แดงส่วนที่เรียบและสม่ำเสมอที่สุดใจกลางภาพ

📐 สมการ Circular Mask ใน color_service.py

import numpy as np

# 1. รัศมี 42% ของขนาดด้านที่สั้นที่สุด
radius = min(h, w) * 0.42
cy, cx = h / 2.0, w / 2.0

# 2. สร้างเรขาคณิตวงกลมด้วยระยะทางแบบยุคลิด
y_idx, x_idx = np.ogrid[:h, :w]
dist_sq = (x_idx - cx)**2 + (y_idx - cy)**2
circle_mask = dist_sq <= (radius**2)

# 3. สกัดพิกเซลเฉพาะเนื้อไข่แดงแท้ 100%
clean_pixels = rgb_img[circle_mask]

การแปลงปริภูมิสี CIELAB และการสกัดคุณลักษณะ 18 มิติ

สไลด์ 07 / 13

ระบบ RGB สะท้อนการเปล่งแสงของหลอดไฟ แต่ไม่ตรงกับการรับรู้สีของตามนุษย์ ระบบจึงแปลงภาพสู่ CIELAB (CIE 1976) ซึ่งสะท้อนความเข้มของเม็ดสีแคโรทีนอยด์ได้อย่างสมบูรณ์แบบ

มิติฟีเจอร์ ระบบสี ความหมายทางกายภาพ พฤติกรรมในไข่แดงแต่ละเกรด
R, G, B sRGB ความเข้มแสงแม่สี (0–255) ไข่แดงทุกฟองจะมีค่า R โดดเด่น และ B ต่ำมาก
L* CIELAB ความสว่าง (Lightness: 0=มืด, 100=สว่าง) ไข่สีส้มเข้ม (เบอร์ 15) ค่า L* จะลดต่ำลงอยู่ที่ ~39
a* CIELAB แกนสีเขียว (-) ถึง สีแดง (+) พระเอกชี้ขาด! ยิ่งไข่สีเข้ม ค่า a* จะพุ่งสูงขึ้นชัดเจน
b* CIELAB แกนสีน้ำเงิน (-) ถึง สีเหลือง (+) สะท้อนปริมาณเม็ดสีเหลืองส้ม (Carotenoids)
📁 ผลลัพธ์ของขั้นตอนนี้: สกัดสถิติ (Mean, Std, Median) ได้ไฟล์ `data/features.csv` ขนาด 647 แถว × 6 มิติหลัก [r, g, b, l, a, b_lab] และคอลัมน์เป้าหมาย fan_score พร้อมสำหรับป้อนให้ AI ฝึกสอน

ทำไม SVR ถึงชนะเลิศ? (Deep Dive SVR Science)

สไลด์ 09 / 13

1. Gaussian RBF Kernel

ความสัมพันธ์ระหว่างค่าสีกับระดับความเข้มไข่แดงมีลักษณะ Non-linear (ไม่เป็นเส้นตรง) ฟังก์ชัน Gaussian RBF สามารถดัดระนาบ Hyperplane ให้โค้งรับพฤติกรรมสีจริงได้อย่างสมบูรณ์แบบ

2. ε-Insensitive Tube

สร้างท่อยอมรับความคลาดเคลื่อน ε = 0.1 ทำให้โมเดล ไม่ถูกรบกวนจากสัญญาณสั่นไหวเล็กๆ แตกต่างจาก OLS Regression ที่พยายามลากเส้นให้ผ่านจุดรบกวนทุกจุด

3. ทฤษฎี Support Vectors

โมเดลตัดสินใจจากเวกเตอร์สำคัญรอบขอบเขต (556 จุด จาก 647 จุด) ทำให้มีความทนทานต่อจุดบกพร่องสูงมาก ไม่ท่องจำข้อมูล (Resistant to Overfitting)

📈 การกระจายตัวของ Support Vectors ในโมเดลจริง

สถิติการกระจายตัวใน ε-Tube:
  • จุดที่อยู่ภายในท่อ (Zero Loss): 91 จุด (14.1%)
  • จุดที่เป็น Support Vectors บนขอบและนอกท่อ: 556 จุด (85.9%)
  • จุดตกค้างหลุดขอบรุนแรง (Slack > 1.0): เพียง 12 จุด
ความสำคัญของพารามิเตอร์:
  • C = 10.0: ควบคุมโทษของจุดที่หลุดนอกท่อ (Trade-off)
  • γ (Gamma) = 0.1667: ควบคุมรัศมีอิทธิพลของแต่ละ Support Vector
  • ε = 0.10: ขนาดความกว้างของช่องว่างปลอดภัยรอบเส้นทำนาย

เมื่อโหลดตัวเลขจาก model_weights.json เข้าสู่หน่วยความจำของสมาร์ตโฟน จะสามารถคำนวณทำนายคะแนนได้ทันทีในเวลาไม่ถึง 1 มิลลิวินาที ผ่านสูตร:

f(x) = ∑ [ αᵢ × exp( -γ ‖ (x - μ)/σ - SVᵢ ‖² ) ] + Intercept

🛠️ ขั้นตอนการคำนวณ 3 สเต็ปบนมือถือ

  1. StandardScaler: นำเวกเตอร์สี 6 มิติ \(x\) มาลบค่าเฉลี่ย \(\mu\) และหารส่วนเบี่ยงเบน \(\sigma\)
  2. RBF Kernel: คำนวณระยะห่างแบบ Euclidean Squared กับ Support Vectors ทั้ง 556 จุด แล้วผ่านฟังก์ชัน Exponential \(\exp(-\gamma d^2)\)
  3. Dot Product & Bias: คูณสะสมกับน้ำหนัก \(\alpha_i\) และบวกค่า Intercept ได้เกรดไข่ทันที

กรรมการสอบมักถามว่า: "ทำไมไม่ใช้โมเดล Deep Learning ยอดนิยมอย่าง YOLOv8 ตรวจจับไข่แดง?" สามารถตอบได้ด้วย 4 เหตุผลทางวิศวกรรม:

ปัจจัยเปรียบเทียบ YOLOv8 (Deep Learning) HSV + Connected Components (ของเรา)
ขนาดโมเดล 15 – 30 MB 0 MB (ใช้สมการทางคณิตศาสตร์) 🏆
เวลาประมวลผล (Latency) 150 – 300 ms (กินแบต, เครื่องร้อน) 10 – 20 ms (เร็วกว่า 10 เท่า) 🏆
ความพึ่งพาไลบรารี ต้องลง TFLite / ONNX (แอปบวม) รัน Native Code บนมือถือได้ทันที 🏆
ความโปร่งใส (Explainability) Black-box ตรวจสอบพิกเซลไม่ได้ White-box อธิบายที่มาได้ตามหลักฟิสิกส์ 🏆
🎯 หมัดเด็ดคำตอบกรรมการ: ใน batch_auto_crop.py ระบบได้สร้างไฟล์พิกัด Bounding Box .txt (Normalized YOLO Format) ครบทั้ง 647 รูปโดยอัตโนมัติ (Auto-Annotation) เพื่อให้นักวิจัยรุ่นต่อไปนำไปเทรน YOLOv8 ได้ทันทีโดยไม่ต้องเสียเวลามานั่ง Label ใหม่เลยแม้แต่วินาทีเดียว!

1. ถ้ามีวัตถุสีส้มอื่น เช่น แครอท ระบบจะตัดภาพผิดพลาดหรือไม่?
ไม่ผิดพลาดครับ เพราะระบบใช้ Connected Component Analysis สแกนแยกวัตถุอิสระ และเลือกล็อกเป้าเฉพาะก้อนที่มีพื้นที่ใหญ่ที่สุด (Largest Blob) ซึ่งไข่แดงมีขนาดใหญ่ถึง 11,975 พิกเซล ในขณะที่แครอทมีขนาดเพียง 1,329 พิกเซล (ต่างกัน 9 เท่า) ระบบจึงตัดแครอททิ้งไป 100% ครับ
2. หลังจากตัดภาพเป็นสี่เหลี่ยมแล้ว ทำไมยังต้องเจาะวงกลม Mask 42% อีกรอบ?
เพราะภาพถ่ายเป็นสี่เหลี่ยมแต่ไข่แดงเป็นวงกลมครับ มุมทั้ง 4 ของภาพที่ตัดแล้วจะยังมีเศษไข่ขาวหรือขอบจานติดมาด้วยเสมอ นอกจากนี้บริเวณขอบไข่แดงมักสะท้อนแสงไฟนีออน การเจาะเฉพาะวงกลมรัศมี 42% ตรงกลาง จะช่วยรับประกันว่าได้ดึงเฉพาะ เนื้อไข่แดงแท้ที่มีสีสม่ำเสมอที่สุด ครับ
3. ทำไมกราฟ Actual vs Predicted ของโมเดล SVR ถึงเป็นเส้นตรง 45 องศา?
เส้นตรงสีแดงคือ Identity Line (y = x) ซึ่งเป็นเส้นอุดมคติที่แสดงว่าโมเดลทำนายได้ตรงกับคะแนนจริง ยิ่งจุดข้อมูลเกาะชิดเส้นตรงมากเท่าใดก็ยิ่งแสดงว่าโมเดลแม่นยำสูง (R² = 0.9185) ส่วนความโค้ง Non-linear ของ SVR RBF จะไปทำงานอยู่ใน Feature Space ระหว่างมิติของค่าสีกับระดับคะแนนครับ
4. ผลการทดลอง A/B Testing ยืนยันอะไรเกี่ยวกับระบบ Auto-Crop?
ยืนยันว่าการตัดภาพด้วย Auto-Crop ช่วยเพิ่มความแม่นยำให้ AI ได้จริงครับ โดยโมเดล SVR มีค่า R² สูงขึ้นจาก 0.9175 เป็น 0.9185 และค่า MAE ลดลงเหลือ 0.6403 เนื่องจากคอมพิวเตอร์ตัดภาพด้วยความสม่ำเสมอในระดับพิกเซลสูงกว่าตามนุษย์ ทำให้ข้อมูลฟีเจอร์สีมีความนิ่งและขจัดสัญญาณรบกวนได้ดีกว่าครับ
