🎨 ส่วนที่ 2: extract_mean_rgb() — สกัดค่าสี RGB จาก Circular Mask 42%

ทำไมต้องใช้ Circular Mask 42%?
ภาพที่ครอปมาจะเป็นสี่เหลี่ยมจัตุรัส แต่ไข่แดงจริงเป็นวงกลม → มุม 4 มุมของภาพจะมีสีพื้นหลัง/ไข่ขาวปะปน
การใช้ วงกลม 42% ตรงกลาง จะดึงเฉพาะ "เนื้อไข่แดงบริสุทธิ์" ตรงกลางภาพ ตัดขอบและพื้นหลังทิ้งทั้งหมด
color_service.pyบรรทัด 112–152
112def extract_mean_rgb(image_input):
130    img_rgb = img.convert('RGB')
131    np_img = np.array(img_rgb)        # แปลง PIL Image → NumPy array 3 มิติ [H, W, 3]
133    h, w, _ = np_img.shape
134    cy, cx = h // 2, w // 2          # หาจุดกลางภาพ
135    radius = int(min(h, w) * 0.42)  # รัศมี = 42% ของด้านที่สั้นกว่า
136    y_coords, x_coords = np.ogrid[:h, :w]  # สร้าง grid พิกัด
137    mask = (x_coords - cx)**2 + (y_coords - cy)**2 <= radius**2
สมการวงกลม: (x - cx)² + (y - cy)² ≤ r² → สร้าง boolean mask รูปวงกลม — pixel ที่อยู่ในวงกลมจะเป็น True ที่เหลือเป็น False
color_service.pyบรรทัด 143–152
143        mean_r = float(np.mean(np_img[:, :, 0][mask]))  # ค่าเฉลี่ย R ของ pixel ในวงกลม
144        mean_g = float(np.mean(np_img[:, :, 1][mask]))  # ค่าเฉลี่ย G ของ pixel ในวงกลม
145        mean_b = float(np.mean(np_img[:, :, 2][mask]))  # ค่าเฉลี่ย B ของ pixel ในวงกลม
148    return {'r': round(mean_r, 2), 'g': round(mean_g, 2), 'b': round(mean_b, 2)}
np_img[:, :, 0][mask] → เลือก channel R ของเฉพาะ pixel ที่ mask เป็น True แล้วคำนวณค่าเฉลี่ย — ได้ค่า "สีแดงเฉลี่ยของเนื้อไข่แดง"

🔬 ส่วนที่ 3: rgb_to_cielab() — แปลง RGB → CIELAB (D65)

ทำไมต้องแปลงเป็น CIELAB?
ปริภูมิสี RGB เป็น device-dependent (สีจะดูต่างกันบนจอต่างชนิด) แต่ CIELAB เป็น perceptually uniform — ระยะห่างของเลขตรงกับสิ่งที่ตามนุษย์เห็น
L* = ความสว่าง (0–100), a* = แดง-เขียว, b* = เหลือง-น้ำเงิน
color_service.pyบรรทัด 155–171
155def rgb_to_cielab(r, g, b):
164    rgb_norm = np.array([[[r / 255.0, g / 255.0, b / 255.0]]], dtype=np.float64)
165    lab_arr = rgb2lab(rgb_norm)[0, 0]  # ใช้ scikit-image แปลง
167    return {
168        'l': round(float(lab_arr[0]), 2),   # L* ความสว่าง
169        'a': round(float(lab_arr[1]), 2),   # a* แดง-เขียว
170        'b': round(float(lab_arr[2]), 2)    # b* เหลือง-น้ำเงิน
171    }
ทำไมใช้ rgb2lab จาก scikit-image? เพราะใช้ D65 illuminant (แสงกลางวัน) ซึ่งเป็นมาตรฐาน ISO และ CIE — ฟังก์ชันนี้ทำ sRGB → Linear RGB → XYZ → CIELAB ให้อัตโนมัติ

HSV คืออะไร?
Hue (สีที่เห็น: 0°=แดง, 30°=ส้ม, 60°=เหลือง) · Saturation (ความสด: 0=เทา, 1=สดจัด) · Value (ความสว่าง: 0=ดำ, 1=สว่างสุด)
ไข่แดงจะอยู่ใน Hue ≈ 20°–56° (สีส้มถึงเหลืองเข้ม) มีความสดสูง (S ≥ 0.314) และไม่มืดเกิน (V ≥ 0.314)

Pipeline คืออะไร?
Pipeline([('scaler', StandardScaler()), ('regressor', SVR(...))]) คือการต่อขั้นตอนเข้าด้วยกัน — เมื่อเรียก pipeline.fit(X, y) มันจะ:

ข้อดี: ป้องกัน data leakage — scaler จะ fit เฉพาะข้อมูล train ไม่ leak ไป test

Stratified 5-Fold คืออะไร?
แบ่งข้อมูลเป็น 5 ส่วนเท่าๆ กัน โดยรักษาสัดส่วนของแต่ละ class ไว้ (เช่น ถ้า class8 มี 10% ของข้อมูลทั้งหมด ทุก fold จะมี class8 ≈ 10%)
วน 5 รอบ: แต่ละรอบใช้ 4 ส่วนเทรน + 1 ส่วนทดสอบ → สลับจนครบ → ได้ค่าเฉลี่ยที่น่าเชื่อถือ

SVR RBF Kernel ทำนายอย่างไร?
สมการที่แอปมือถือคำนวณ:
f(x) = Σᵢ αᵢ · exp(−γ · ||x − sᵢ||²) + b

สัญลักษณ์ค่าใน JSONความหมาย
x(คำนวณจากภาพใหม่)Features 6 ตัว [R,G,B,L*,a*,b*] ที่ปรับด้วย scaler แล้ว
sᵢsupport_vectors[i]จุดอ้างอิง 556 จุด (เรียนรู้จากการเทรน)
αᵢdual_coef[i]น้ำหนักของแต่ละ support vector
γgammaควบคุม "ความกว้าง" ของ kernel (ค่ายิ่งสูง ยิ่ง sensitive)
binterceptค่า bias เลื่อนผลลัพธ์ขึ้น/ลง
