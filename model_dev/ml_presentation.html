ขั้นตอนที่ 1: การตรวจจับและตัดภาพอัตโนมัติ (Data Preprocessing & Auto-Crop)

📄 batch_auto_crop.py

หน้าที่ของขั้นตอนนี้: ค้นหาตำแหน่งก้อนไข่แดงในภาพถ่าย (Object Localization) และตัดภาพ (Crop) ออกมาเป็นสี่เหลี่ยมจัตุรัสที่มีไข่แดงอยู่กึ่งกลางภาพพอดี โดยที่ ผู้ใช้ไม่ต้องใช้นิ้วลากกรอบเอง และระบบมีความแข็งแกร่งในการตัดสิ่งรบกวนภายนอกทิ้งทั้งหมด

🔍 1.1 หลักการกรองสีด้วยปริภูมิสี HSV

แทนที่จะมองเป็นแม่สี RGB ระบบจะแปลงภาพเป็นปริภูมิสี HSV (Hue, Saturation, Value) เพื่อแยก "เฉดสีแท้จริง" ออกจาก "ความสว่าง": 

# 1. แปลงภาพเป็น HSV
hsv = rgb2hsv(arr / 255.0)
h, s, v = hsv[:, :, 0] * 360.0, hsv[:, :, 1], hsv[:, :, 2]

# 2. หน้ากากกรองเฉพาะสีไข่แดง (Hue 5°-55°, Saturation >= 0.25, Value >= 0.20)
mask = (h >= 5.0) & (h <= 55.0) & (s >= 0.25) & (v >= 0.20)
  • Hue (5° – 55°): ครอบคลุมตั้งแต่สีส้มเข้ม (ไข่เบอร์ 15) จนถึงสีเหลืองอ่อน (ไข่เบอร์ 4)
  • Saturation (≥ 0.25): จุดชี้ขาดสำคัญ! บังคับว่าต้องมีความสดของสีเพียงพอ ทำให้สามารถ ตัดพื้นหลังสีครีม จานสีขาว และไข่ขาวทิ้งได้ทั้งหมด 100% เพราะสีเหล่านั้นมีค่าความสดต่ำ (S < 0.25)
  • Value (≥ 0.20): ตัดเงามืดและขอบมืดทิ้ง

🥕 1.2 การคัดแยกสิ่งรบกวนด้วย Connected Component Analysis (เคสแครอท)

ในกรณีที่มีวัตถุสีส้มอื่นอยู่ในภาพ (เช่น ชิ้นแครอท หรือมะเขือเทศ) หากใช้การกวาดหาพิกเซลแบบเหมาเข่ง กรอบจะลากคลุมทั้งแครอทและไข่แดง ทำให้จุดกึ่งกลางเบี้ยว เราจึงอัปเกรดระบบด้วย การวิเคราะห์แยกก้อนวัตถุอิสระ: 

from skimage.measure import label, regionprops

# จัดกลุ่มพิกเซลที่เกาะติดกันเป็นก้อนๆ
lbl = label(mask)
props = regionprops(lbl)

# เลือกเฉพาะ "ก้อนที่มีขนาดพื้นที่ใหญ่ที่สุดเพียงก้อนเดียว"
largest = max(props, key=lambda p: p.area)
min_y, min_x, max_y, max_x = largest.bbox
cy, cx = int(largest.centroid[0]), int(largest.centroid[1])
💡
ผลการทำงานจริง: ก้อนแครอทมีขนาดพื้นที่เพียง 1,329 พิกเซล ในขณะที่ก้อนไข่แดงมีขนาดใหญ่ถึง 11,975 พิกเซล (ใหญ่กว่า 9 เท่า) ระบบจึงเลือกตีกรอบเฉพาะก้อนไข่แดง และตัดแครอททิ้งไปโดยอัตโนมัติ 100%!

📐 1.3 การคำนวณกรอบสี่เหลี่ยมจัตุรัส (Square Bounding Box)

เป้าหมายของขั้นตอนนี้คือการเปลี่ยนจาก "จุดศูนย์กลางของไข่แดง (cx, cy)" ให้กลายเป็น "พิกัดมุมบนซ้าย (x₁, y₁) และมุมล่างขวา (x₂, y₂)" เพื่อให้คำสั่งตัดภาพ image.crop() สามารถตัดภาพสี่เหลี่ยมจัตุรัสครอบไข่แดงได้พอดีเป๊ะ โดยมีขั้นตอนการคำนวณ 3 สเต็ปดังนี้:

แผนภาพแสดงเรขาคณิตการหาพิกัดตัดภาพจากจุดกึ่งกลาง (cx, cy) สู่มุมบนซ้าย (x₁, y₁)

สเต็ป 1: หาขนาดกล่อง (Box Size)

Box Size = max(Width, Height) × 1.05
  • Width & Height: วัดจากขอบพิกเซลจริงของไข่แดง Width = max_x - min_x และ Height = max_y - min_y
  • max(): เลือกด้านที่ยาวที่สุด เพื่อให้ครอบคลุมไข่แดงมิดชิดทั้งใบ ไม่แหว่ง
  • × 1.05: เผื่อขอบ (Padding 5%) ไม่ให้กรอบเบียดชิดเนื้อไข่เกินไป

สเต็ป 2: หามุมบนซ้าย (x₁, y₁)

x₁ = cx - (Size / 2)
y₁ = cy - (Size / 2)
  • (cx, cy): จุดกึ่งกลางมวล (Centroid) ที่เฉลี่ยจากพิกเซลไข่แดงทั้งหมด
  • - Size/2: คำสั่ง crop() ต้องการพิกัดมุมบนซ้าย จึงต้องถอยไปทางซ้ายครึ่งกล่อง และถอยขึ้นข้างบนครึ่งกล่อง

สเต็ป 3: หามุมขวาล่าง & Clamp

x₂ = x₁ + Size  |  y₂ = y₁ + Size
  • มุมขวาล่าง: บวกก้าวไปข้างหน้าตามขนาดกล่อง
  • คำสั่ง Clamp: x1 = max(0, x1) ป้องกันพิกัดติดลบหรือทะลุออกนอกขอบภาพ รับประกัน 100% ว่าโปรแกรมจะไม่พัง
🔢
ตัวอย่างการคำนวณจริง: สมมุติวัดไข่แดงได้กว้าง 200 px, สูง 180 px, จุดกึ่งกลาง (cx=500, cy=400)
• Box Size: max(200, 180) × 1.05 = 210 px (ครึ่งกล่อง = 105 px)
• มุมบนซ้าย (x₁, y₁): x₁ = 500 - 105 = 395,   y₁ = 400 - 105 = 295
• มุมขวาล่าง (x₂, y₂): x₂ = 395 + 210 = 605,   y₂ = 295 + 210 = 505
➔ สั่งตัด: image.crop((395, 295, 605, 505)) ได้ภาพสี่เหลี่ยมจัตุรัส 210 × 210 พิกเซล โดยมีไข่แดงอยู่กึ่งกลางภาพพอดีเป๊ะ!

ขั้นตอนที่ 2: การสกัดฟีเจอร์ค่าสี (Feature Extraction & Color Space)

📄 build_features.py + color_service.py

หน้าที่ของขั้นตอนนี้: นำภาพที่ตัดขอบเป็นสี่เหลี่ยมจัตุรัสทั้ง 647 รูป มาสกัดคุณลักษณะเชิงปริมาณของสี (Color Features) จำนวน 6 ฟีเจอร์ เพื่อใช้เป็นตัวแปรต้นในการฝึกสอนโมเดล Machine Learning

🎯 2.1 ทำไมต้องมี Center Circular Mask 42% อีกรอบ?

แม้ว่าภาพจะถูกตัดเข้ามาเป็นสี่เหลี่ยมชิดไข่แดงแล้ว แต่ "รูปภาพดิจิทัลเป็นสี่เหลี่ยม แต่ไข่แดงเป็นวงกลม":

  • ตัดมุมทั้ง 4 มุมทิ้ง: มุมทั้งสี่ของกรอบสี่เหลี่ยมจะติดเศษไข่ขาวหรือขอบจานมาเสมอ หากนำมาเฉลี่ยรวมจะทำให้ค่าสีเพี้ยน
  • ตัดแสงสะท้อนขอบไข่ (Specular Highlights): บริเวณขอบไข่แดงจะมีความโค้งนูนและสะท้อนแสงไฟจากหลอดไฟในห้อง
  • รัศมี 42% (เว้นขอบ 8%): สร้างมาสก์วงกลมรัศมี R = min(W, H) × 0.42 เพื่อเจาะดูดเฉพาะ "เนื้อไข่แดงแท้ๆ ที่มีความสม่ำเสมอที่สุด"

🌈 2.2 การแปลงปริภูมิสีจาก RGB สู่ CIELAB (มาตรฐาน CIE 1976)

ระบบสี RGB ถูกออกแบบมาสำหรับหลอดภาพ ไม่ได้สะท้อนการรับรู้สีของตามนุษย์ (Perceptually Non-uniform) ระบบจึงแปลงเป็น CIELAB ซึ่งแยกความสว่างออกจากเนื้อสีอย่างสมบูรณ์:

ฟีเจอร์ ระบบสี ความหมายทางวิทยาศาสตร์ พฤติกรรมในไข่แดง
R, G, B sRGB ความเข้มแสงแม่สี แดง, เขียว, น้ำเงิน (0–255) ไข่แดงจะมีค่า R สูงเด่น และค่า B ต่ำมาก
L* CIELAB ความสว่าง (Lightness: 0=ดำสนิท, 100=ขาวบริสุทธิ์) ไข่สีเข้ม (เบอร์ 15) ค่า L* จะลดลงอยู่ที่ ~39
a* CIELAB แกนสีเขียว (-) ถึง สีแดง (+) พระเอกสำคัญ! ยิ่งไข่สีเข้ม ค่า a* จะพุ่งสูงขึ้นเป็นบวกมาก
b* CIELAB แกนสีน้ำเงิน (-) ถึง สีเหลือง (+) สะท้อนความเข้มข้นของเม็ดสีแคโรทีนอยด์สีเหลืองส้ม

ผลลัพธ์ของขั้นตอนนี้: ได้ไฟล์ตาราง `data/features.csv` ขนาด 647 แถว × 6 คอลัมน์ฟีเจอร์ [r, g, b, l, a, b_lab] และคอลัมน์เป้าหมาย fan_score พร้อมสำหรับการฝึกโมเดล

🧠 3.3 เหตุผลทางวิทยาศาสตร์ที่ SVR (RBF Kernel) ชนะเลิศ

  1. RBF Kernel (Radial Basis Function): ความสัมพันธ์ระหว่างค่าสีกับระดับความเข้มของไข่แดงมีความเป็น Non-linear (ไม่เป็นเส้นตรง) ซึ่งฟังก์ชัน Gaussian RBF สามารถดัดระนาบทำนายให้โค้งรับพฤติกรรมสีจริงได้อย่างสมบูรณ์
  2. ε-Insensitive Loss Tube: กำหนดท่อยอมรับความคลาดเคลื่อน ε = 0.1 ทำให้โมเดลไม่ถูกรบกวนจากแสงสะท้อนหรือพิกเซลแปลกแยกบางจุด
  3. ทฤษฎี Support Vectors: โมเดลตัดสินใจจากจุดสำคัญรอบขอบเขต (ใช้ Support Vectors 556 จุด จาก 647 จุด) ทำให้มีความทนทานต่อ Overfitting สูงกว่า Decision Tree

1. ทำไมถึงเลือกใช้ HSV Color Masking แทนที่จะใช้ YOLOv8 ตรวจจับไข่แดง? (คำถามยอดฮิต)

สามารถตอบกรรมการด้วย หลักการทางวิศวกรรม (Engineering Rationale) 4 ประการดังนี้ครับ:

  1. หลีกเลี่ยงการทำ Over-Engineering (หลักการ Occam's Razor):
    โจทย์ของระบบคือการตีกรอบไข่แดง 1 ฟองในจาน ซึ่งไข่แดงมีเอกลักษณ์เฉพาะตัวทางสีที่เด่นชัดมาก (Distinct Color Signature) คือมีความสดของสีสูง (Saturation ≥ 0.25) และอยู่ในช่วงสีส้ม-เหลืองชัดเจน การนำโมเดล Deep Learning ขนาดยักษ์อย่าง YOLO มาใช้เพื่อตีกรอบวัตถุเพียงชิ้นเดียว ถือเป็นการ "ขี่ช้างจับตั๊กแตน" และเพิ่มภาระให้กับระบบโดยไม่จำเป็นครับ
  2. ประสิทธิภาพและความประหยัดทรัพยากรบนสมาร์ตโฟน (Mobile Constraints):
    ปัจจัยเปรียบเทียบ YOLOv8 (Deep Learning) HSV + Connected Components (ของเรา)
    ขนาดไฟล์โมเดล 15 – 30 MB 0 MB (ใช้สมการคณิตศาสตร์) 🏆
    เวลาประมวลผล (Latency) 150 – 300 ms (กินแบต, เครื่องร้อน) 10 – 20 ms (เร็วขึ้น 10 เท่า) 🏆
    ความพึ่งพาไลบรารี ต้องลง TFLite / ONNX Runtime (แอปบวม) รัน Native Code บนมือถือได้ทันที 🏆
  3. ความโปร่งใสและอธิบายได้ (Explainable AI / White-box):
    ระบบ HSV + Connected Components สามารถอธิบายที่มาของทุกพิกเซลได้ตามหลักวิทยาศาสตร์ แตกต่างจาก Deep Learning ที่เป็น Black-box และผ่านการทดสอบจริงกับภาพ 647 ภาพ รวมถึงเคสยากอย่างการคัดแยกชิ้นแครอทสีส้ม (1,329 px) ออกจากไข่แดง (11,975 px) ได้สำเร็จ 100%
  4. หมัดเด็ด: เราเตรียมข้อมูลพร้อมสำหรับ YOLO ไว้เรียบร้อยแล้ว (Auto-Annotation):
    ในกระบวนการทำงานของ batch_auto_crop.py ระบบได้สร้างไฟล์พิกัด Bounding Box .txt (Normalized Coordinates: class, x, y, w, h) ตามมาตรฐานสากลของ YOLO ไว้ครบทั้ง 647 รูปโดยอัตโนมัติ ทำให้ชุดข้อมูลนี้พร้อมส่งต่อให้ทีมวิจัยรุ่นต่อไปนำไป Train โมเดล YOLOv8 ได้ทันทีโดยไม่ต้องเสียเวลามานั่งตีกรอบ Label ใหม่เลยแม้แต่วินาทีเดียวครับ!
2. ถ้าในภาพมีวัตถุสีส้มอื่น เช่น แครอท ระบบจะตัดภาพผิดพลาดหรือไม่?
ไม่ผิดพลาดครับ เพราะระบบได้เพิ่มอัลกอริทึม Connected Component Analysis โดยทำหน้าที่สแกนแยกวัตถุสีส้มที่เกาะติดกันออกเป็นกลุ่มๆ จากนั้นคำนวณพื้นที่ (Area) ของแต่ละก้อน และเลือกเฉพาะก้อนที่มีขนาดใหญ่ที่สุด (Largest Blob) ซึ่งก้อนไข่แดงมีขนาดใหญ่กว่าสิ่งรบกวนทั่วไปเกือบ 10 เท่า ระบบจึงล็อกเป้าเฉพาะก้อนไข่แดง และตัดชิ้นแครอททิ้งไปโดยอัตโนมัติครับ
3. หลังจากตัดภาพเป็นสี่เหลี่ยมแล้ว ทำไมยังต้องเจาะวงกลม Mask 42% อีกรอบ?
เพราะภาพถ่ายเป็นสี่เหลี่ยมแต่ไข่แดงเป็นวงกลมครับ มุมทั้ง 4 มุมของภาพที่ตัดแล้วจะยังมีเศษไข่ขาวหรือขอบจานติดมาด้วยเสมอ นอกจากนี้บริเวณขอบของไข่แดงมักมีแสงสะท้อนวาวจากหลอดไฟ การเจาะเฉพาะวงกลมรัศมี 42% ตรงกลาง จะช่วยรับประกันว่าเราได้ดึงเฉพาะ เนื้อไข่แดงแท้ๆ ที่มีสีสม่ำเสมอที่สุด และตรงกับข้อมูลที่โมเดลใช้ในการฝึกสอนครับ
4. ทำไมกราฟ Actual vs Predicted ของโมเดล SVR ถึงเป็นเส้นตรง 45 องศา?
เส้นตรงสีแดงคือ Identity Line (y = x) ซึ่งเป็นเส้นอุดมคติที่แสดงว่าถ้าโมเดลทำนายได้ตรงกับความเป็นจริง จุดข้อมูลจะตกอยู่บนเส้นตรงนี้ครับ ยิ่งจุดเกาะชิดเส้นตรงมากเท่าใดก็ยิ่งแสดงว่าโมเดลมีความแม่นยำสูง (ซึ่งโมเดลของเราได้ R² = 0.9185) ส่วนความโค้ง (Non-linearity) ของ SVR RBF นั้นจะไปทำงานอยู่ใน Feature Space ระหว่างมิติของค่าสี (RGB, CIELAB) กับระดับคะแนนครับ
5. ผลการทดลอง A/B Testing ยืนยันอะไรเกี่ยวกับระบบ Auto-Crop?
ผลการทดลองยืนยันว่าการใช้ระบบ Auto-Crop อัตโนมัติช่วยเพิ่มความแม่นยำให้โมเดล AI ได้จริงครับ โดยโมเดล SVR มีค่า R² สูงขึ้นจาก 0.9175 เป็น 0.9185 และค่าความคลาดเคลื่อน MAE ลดลงเหลือ 0.6403 เนื่องจากระบบคอมพิวเตอร์ตัดภาพด้วยความสม่ำเสมอในระดับพิกเซลสูงกว่าสายตามนุษย์ ทำให้ข้อมูลฟีเจอร์สีมีความนิ่งและขจัดสัญญาณรบกวนได้ดีกว่าครับ
